# Bounded Codex task

## Outcome
Verify a local TaskBoard dashboard through a real browser and convert one visible defect into reproducible evidence.

## Task prompt
Test the priority filter at desktop and mobile viewports. Capture the failing state, repair only the causal UI layer, and repeat the path.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The evidence includes pre-repair failure, scoped patch and passing desktop/mobile re-test.
