# Bounded Codex task

## Outcome
Compare read-only, workspace-write and approval boundaries using safe commands and an explicit consequence matrix.

## Task prompt
Probe only the supplied lab paths. Do not alter files outside the lab. Explain every boundary and record whether the action was allowed, blocked or approved.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The log contains safe probes for three permission cases and a least-privilege recommendation supported by results.
