# flyer-design

## Steps
1. Read the brief and $brand-voice. List the must-carry items.
2. Generate with $imagegen at the requested size: A5 portrait for print,
   1:1 for posts, 9:16 for stories. Real food photography; text large,
   high contrast, never over a busy area; 10mm margin for print.
3. Save to creative/<campaign>/ with the prompt used beside each image.
4. List every word of text on each image, line by line.
5. Compare each fee, date and name with the source. If any differ,
   regenerate with the exact fix named.

## Never
Never invent a course, fee, date or discount.
