# Bounded Codex task

## Outcome
Deliver a bounded TaskBoard improvement, evaluate it against the baseline and make a pilot, expand, hold or stop recommendation.

## Task prompt
Use the full Codex workflow to improve TaskBoard. Preserve user changes, verify every acceptance criterion, compare with baseline, and issue a conditional adoption recommendation.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The solution works, the evidence pack covers correctness, efficiency and risk, and the recommendation states limits, controls, owner and review date.
