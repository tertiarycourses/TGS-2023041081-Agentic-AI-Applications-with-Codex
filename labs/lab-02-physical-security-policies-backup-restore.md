# Lab 02 - Physical Security, Policies, and Backup Restore

## Objectives

- Identify physical security controls.
- Compare administrative and technical controls.
- Compare backup and restore types.

## Steps

### Step 1 - Build physical security table

| Control | Purpose |
| --- | --- |
| Locked server room | Prevent unauthorized physical access |
| Visitor sign-in | Track physical visitors |
| Mantrap | Control access to sensitive areas |
| Cable lock | Reduce laptop theft |
| Secure disposal | Prevent data recovery from old media |
| Removable media policy | Control USB and external drive risk |

### Step 2 - Identify computer security controls

Create checklist:

```text
[ ] Screen lock enabled
[ ] Full disk encryption enabled where required
[ ] USB storage restricted where required
[ ] BIOS or firmware password considered
[ ] Boot from external media controlled
[ ] Device inventory maintained
```

### Step 3 - Classify policy types

| Control type | Example |
| --- | --- |
| Administrative | Acceptable use policy |
| Administrative | Backup policy |
| Technical | MFA enforcement |
| Technical | Firewall rule |
| Technical | Antivirus scanning |

### Step 4 - Compare backup types

| Backup type | Description | Restore consideration |
| --- | --- | --- |
| Full | Copies all selected data | Simplest restore, more storage |
| Incremental | Copies changes since last backup | Faster backup, more restore steps |
| Differential | Copies changes since last full backup | Moderate backup and restore effort |


Submit:
