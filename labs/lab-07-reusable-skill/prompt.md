# Bounded Codex task

## Outcome
Package a test-triage workflow as a reusable skill and measure trigger precision with positive and near-miss prompts.

## Task prompt
Create a narrowly triggered skill for Python unittest failure triage. Include evidence requirements and test one prompt that must not trigger it.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The skill passes structural checks and its evaluation shows correct trigger and near-miss behavior.
