# Lab 10 - Capstone: Network Security Baseline and Readiness

## Objectives

- Create an end-to-end network security baseline.
- Connect recommendations to Pearson Network Security objectives.
- Complete certification readiness review.

## Capstone Task

Create a network security baseline report for Contoso.

Your report should cover:

- Defense in depth.
- Physical and policy controls.
- Attack recognition.
- OS hardening.
- Authentication and permissions.
- Auditing and encryption.
- Wireless and protection devices.
- Isolation and protocol security.
- Email, browser, and anti-malware protection.

### Step 6 - Complete readiness checklist


### Step 7 - Present the capstone

Prepare a five-minute explanation:

1. What are Contoso's biggest network security risks?
2. Which controls should be implemented first?
3. How does the design use defense in depth?
4. How will logs and audits support non-repudiation?
5. How are backups and anti-malware handled?
6. Which exam objectives does your plan demonstrate?
