# Bounded Codex task

## Outcome
Turn an outcome contract into a bounded plan, implement one TaskBoard feature and verify the changed behavior.

## Task prompt
Add priority filtering to TaskBoard. Preserve the CLI contract, add tests, and finish only when the focused and regression checks pass.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The diff is scoped, the new behavior is tested, all supplied tests pass and the final summary cites evidence.
