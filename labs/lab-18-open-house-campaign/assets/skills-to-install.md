# Marketing skills to install (Lab 18)

Run in your cook-and-bake folder, then start a new Codex chat.

    npx skills add https://github.com/coreyhaines31/marketingskills \
      --skill lead-magnets -a codex -y

    npx skills add https://github.com/coreyhaines31/marketingskills \
      --skill seo-audit -a codex -y

    npx skills add https://github.com/bytedance/deer-flow \
      --skill newsletter-generation -a codex -y

Read each SKILL.md first. Commit the updated skills-lock.json.
