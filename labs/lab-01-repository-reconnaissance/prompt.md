# Bounded Codex task

## Outcome
Inspect a TaskBoard repository, identify its instruction and test boundaries, and record a measurable baseline before any edit.

## Task prompt
Inspect only. Map applicable instructions, runtime, tests and likely change files. Do not edit. Return evidence for every conclusion.

## Constraints
- Work only in the learner copy inside this lab.
- Preserve public behavior unless the task explicitly changes it.
- Do not change expected tests to force a pass.
- Do not access the network, external accounts, credentials or personal data.

## Definition of done
The report names the applicable instruction chain, test command, baseline result and scoped target files.
