# Learner Guide - Pearson Vue Certified IT Specialist Network Security Training

## Course Overview

This learner guide supports **TGS-2024051414 - Pearson Vue Certified IT Specialist Network Security Training**. The course uses a practical case study called **Contoso Network Security Baseline**, where learners review a small training provider's network, endpoints, user access, wireless environment, logs, and defensive controls.

The labs align to Pearson VUE IT Specialist Network Security objectives: defense in depth, operating system security, network device security, and secure computing.

## Prerequisites

Learners should have:

- Basic computer and internet literacy.
- Basic understanding of files, users, Wi-Fi, passwords, and websites.
- Basic comfort using Windows or another desktop operating system.
- A laptop with internet access.

No prior professional security experience is required.

## Recommended Tools

- Windows Security or equivalent endpoint protection.
- Event Viewer or another local log viewer.
- PowerShell, Command Prompt, Terminal, or shell.
- Spreadsheet tool.
- diagrams.net.
- Browser settings page.

## Learning Outcomes

By the end of this course, you will be able to:

1. Explain defense in depth, CIA, non-repudiation, risk, vulnerability, and least privilege.
2. Identify physical security controls and policy types.
3. Recognize common malware, web, password, MITM, and social engineering attacks.
4. Build backup and restore decision tables.
5. Apply OS hardening and patch management checklists.
6. Explain MFA, password policies, Run As, sudo, Kerberos, and permissions.
7. Review audit policies and logs for accountability.
8. Explain encryption, certificates, BitLocker, and VPN protection.
9. Compare wireless controls, firewalls, IDS, IPS, SIEM, content filtering, and isolation methods.
10. Design a network security baseline and readiness checklist.

## Case Study: Contoso Network Security Baseline

Contoso has:

- Staff laptops and a training room.
- Staff Wi-Fi and guest Wi-Fi.
- A small file share.
- A public website.
- Admin accounts.
- A firewall/router.
- Basic endpoint protection.
- Manual backups.

The goal is to create a practical network security baseline with layered controls.

## Lab Deliverables

- Authentication and permissions plan.

- Wireless and protection device diagram.

## Safety and Ethics Rules

- Do not scan or test systems without permission.
- Use only sample logs or your own lab machine.
- Do not change live security controls unless instructed.
- Do not share private screenshots, keys, passwords, or logs.

## Certification Study Tips

- Know the difference between threat, risk, vulnerability, and attack surface.
- Practice explaining administrative and technical controls.
- Memorize common secure and insecure protocols.
- Understand how permissions, auditing, and encryption work together.
- Be able to compare firewall, IDS, IPS, SIEM, and isolation methods.
